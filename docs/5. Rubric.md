# Rubric

Use this project rubric to understand and assess the project criteria.

## Statistical Analyses

### Criteria

Correct use of the Binomial Distribution.

### Submission Requirements

All probabilities associated with binomial distribution are calculated correctly.

### Criteria

Correct use of conditional probability calculations

### Submission Requirements

All probabilities associated with conditional probabilities are calculated correctly.

### Criteria

Correct use of Bayes' Rule calculations

### Submission Requirements

All probabilities associated with Bayes' Rule are calculated correctly.

### Criteria

Provide assumptions of the binomial distribution

### Submission Requirements

When using the binomial distribution, provide the required assumptions.

## Suggestions to Make Your Project Stand Out

- Show your work when calculating each solution.
- Do you believe that the assumptions of the binomial distribution are violated? Why are why not?

## Submission Notes

Before you submit, have a final check that your submission has met all items in the Project Rubric at a level of "meets specifications".

There are two methods for submitting. Select the appropriate submission method based on the template that you used.

1. **Project Link**: Use this option if you opted for the Google Slides template. Make sure to update the access so that anyone with the link can view. Then you will submit the viewable link.

2. **Single File**: Use this option if you opted for the MS PowerPoint template. Save the completed presentation deck containing your results as a PDF file and submit this file.
